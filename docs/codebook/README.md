# Urban Institute codebook (metadata)

Saved copies of Urban's three metadata endpoints, fetched on 2026-11-23 from `https://educationdata.urban.org/api/v1/`:

| File | Endpoint | What it holds |
|---|---|---|
| `api-endpoints.json` | `/api-endpoints/` | every endpoint, its path arguments and years available |
| `api-variables.json` | `/api-variables/` | every variable, its label, type and special values |
| `api-downloads.json` | `/api-downloads/` | downloadable files and codebooks |

These are the project's source of truth for field names, category codes and special values (see `docs/data_dictionary.md`).

These files cover all datasets in the portal, not only Virginia. Raw data files are never committed.
